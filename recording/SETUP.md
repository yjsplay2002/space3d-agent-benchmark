# 촬영 세팅 — 얼굴 풀샷 → 우하단 원형 + 화면

목표: 처음엔 얼굴과 배경이 보이다가, 얼굴이 우하단 원 안으로 줄어들고
그 뒤로 내가 조작하는 컴퓨터 화면이 깔리는 구성.

이 맥의 현재 상태 기준 (2026-07-28 확인):
- OBS **32.0.2** 설치됨 · 플러그인 없음 · 씬은 초기 상태
- 카메라: FaceTime HD / **iPhone (연속성 카메라)**
- 마이크: MacBook Pro 내장 / LS27B61x 모니터
- 디스플레이 2개 (내장 + LS27B61x)

---

## 0. 먼저 설치할 것 하나

**Move 플러그인** — 얼굴이 "줄어들며 이동하는" 애니메이션을 OBS 안에서
처리해 준다. 이게 없으면 장면이 그냥 컷으로 바뀐다.

https://obsproject.com/forum/resources/move.913/

받아서 설치한 뒤 OBS를 다시 켠다. `필터` 목록에 `Move` 항목들이 생기면 성공.

> 플러그인 없이 가려면: 두 장면을 컷으로 전환하고, 편집 단계에서 축소
> 애니메이션을 넣는다. 다만 이 맥에 편집 앱이 없어서(Final Cut·DaVinci
> 모두 미설치) 플러그인 쪽이 훨씬 빠르다.

---

## 1. 카메라는 iPhone을 쓴다

FaceTime HD보다 화질 차이가 크다. iPhone을 맥 근처에 두고 같은 Apple 계정,
Wi-Fi·블루투스 켜두면 OBS 영상 캡처 장치 목록에 `Lucas의 iPhone 카메라`로
잡힌다. 거치대에 가로로 세워둘 것.

- 해상도 1920×1080, 30fps (60fps는 말하는 영상엔 불필요)
- 얼굴이 화면 좌측 또는 우측 1/3에 오도록. 정중앙은 나중에 원형으로 줄일 때
  구도가 어색해진다

## 2. 마이크

내장 마이크도 되지만 방 울림이 그대로 들어간다. 외장 마이크가 있으면 그걸 쓰고,
없으면 **입에서 30cm 이내**로 노트북을 두고 녹음한다.

OBS `설정 → 오디오 → 마이크/보조 오디오`에서 장치 지정.
`필터` 에서 아래 순서로 건다:

```
1. 노이즈 억제 (RNNoise)     방 소음 제거
2. 노이즈 게이트              닫힘 -35dB / 열림 -30dB
3. 컴프레서                   비율 4:1, 임계값 -18dB
4. 게인                       최종 피크가 -6dB 근처가 되게
```

말할 때 미터가 노란 구간(-12 ~ -6dB)에서 움직이면 맞다. 빨간색이 뜨면 게인을 내린다.

## 3. 장면 두 개를 만든다

### 장면 A — `인트로 · 얼굴`

| 소스 | 설정 |
|---|---|
| `카메라` (영상 캡처 장치) | iPhone · 화면 꽉 차게 |

이게 도입부다. 얼굴과 배경이 같이 보인다.

### 장면 B — `본편 · 화면 + 얼굴`

아래에서 위 순서로 쌓는다 (OBS 소스 목록에서는 위가 앞에 보인다):

| 순서 | 소스 | 설정 |
|---|---|---|
| 2 (위) | `카메라` | 장면 A와 **같은 소스를 복사가 아니라 '기존 항목 추가'** 로 넣는다 |
| 1 (아래) | `화면` (디스플레이 캡처) | 덱을 띄워둘 디스플레이 선택 |

**카메라를 '기존 항목 추가'로 넣는 게 핵심이다.** 새로 만들면 장치가 두 번
열려서 충돌하고, Move 플러그인도 같은 소스로 인식하지 못한다.

---

## 4. 얼굴을 원형으로 만든다

장면 B의 `카메라` 소스에 필터를 두 개 건다.

**① 자르기/채우기** — 카메라가 16:9라 그대로 마스크를 씌우면 타원이 된다.
좌우를 잘라 정사각형으로 만든다. 1920×1080이면 좌 420 / 우 420.

**② 이미지 마스크/블렌드**
- 유형: `알파 마스크 (알파 채널)`
- 경로: `~/orca/projects/coding_benchmark/recording/circle-mask.png`

이 파일은 이미 만들어 뒀다. 1024×1024, 가장자리 4px 안티에일리어싱이 들어가
계단 현상이 안 보인다.

원 둘레에 테두리를 넣고 싶으면 그 위에 `색상 소스`로 원형 링 이미지를 하나 더
얹으면 되지만, 없어도 충분하다.

---

## 5. 얼굴이 줄어들며 이동하게 만든다

장면 A의 `카메라` 소스에 **`Move Value` 가 아니라 `Move Source` 필터**를 건다.
설정에서:

- 대상: `카메라`
- 전환 시간: `700ms`
- 이징: `Ease In and Out` / `Cubic`

그리고 장면 전환을 `Move` 로 지정한다:
`설정 → 일반 → 장면 전환` 또는 전환 목록에서 `+` → `Move`.

Move 전환은 **두 장면에 같은 이름의 소스가 있으면 그 소스의 위치·크기를
자동으로 보간한다.** 그래서 3번에서 '기존 항목 추가'를 쓴 것이다.

장면 A에서는 카메라가 전체 화면, 장면 B에서는 우하단 원형 — 전환을 걸면
얼굴이 줄어들며 우하단으로 이동한다.

### 우하단 위치 잡기

1920×1080 기준 원 지름 320px 정도가 적당하다.

```
크기   320 × 320
위치   X 1520   Y 700     (오른쪽·아래에서 각 80px 여백)
```

너무 크면 화면을 가리고, 너무 작으면 표정이 안 읽힌다. 300~360 사이에서 조절.

---

## 6. 화면을 어떻게 보여줄 것인가

디스플레이가 두 개니까 이렇게 쓴다:

- **LS27B61x (외부 모니터)** — 덱과 브라우저. 이쪽을 캡처한다
- **내장 화면** — OBS 제어판, 대본

덱은 전체화면으로 띄운다. `space3d-video-deck.vercel.app` 을 열고
`⌘ + Shift + F` 또는 브라우저 전체화면. 좌우 화살표로 넘긴다.

대본 04번에서 배포 사이트를 실제로 열어 조작하는 구간이 있다. 그때는
브라우저 탭만 바꾸면 되고 장면 전환은 필요 없다.

---

## 7. 녹화 설정

`설정 → 출력 → 녹화` 에서:

```
녹화 형식      MKV        중간에 튕겨도 파일이 살아남는다. 끝나고 MP4로 다시 담기
인코더         Apple VT H.264 하드웨어      맥에서 CPU를 거의 안 먹는다
속도 제어      CQP
CQ 수준        18         낮을수록 고화질. 18이면 유튜브 업로드에 충분
```

`설정 → 비디오`:
```
기본 해상도    1920×1080
출력 해상도    1920×1080
FPS           30
```

**오디오 트랙을 분리해 두면 나중에 편하다.** `설정 → 출력 → 녹화 → 오디오 트랙`
에서 1번(전체)과 2번(마이크만) 둘 다 체크. 소리 문제가 생겨도 마이크만 따로
꺼낼 수 있다.

---

## 8. 촬영 순서

1. 덱을 외부 모니터에 전체화면으로 띄운다
2. 대본을 내장 화면에 띄운다 (`video/script.md`)
3. OBS를 장면 A로 두고 녹화 시작
4. 카메라를 보며 인트로 나레이션 (대본 01번) — **약 42초**
5. 장면 B로 전환 → 얼굴이 우하단으로 줄어든다
6. 이후 대본 순서대로 덱을 넘기며 진행
7. 04번 구간에서 브라우저로 배포 사이트를 열어 실제 조작
8. 마지막 슬라이드까지 끝나면 녹화 종료

**한 번에 다 찍으려 하지 않는다.** 슬라이드 단위로 끊어 찍고 나중에 붙이는
편이 훨씬 빠르다. 실수하면 그 슬라이드만 다시 찍으면 된다.

## 9. 자주 걸리는 것

| 증상 | 원인·해결 |
|---|---|
| 화면 캡처가 검게 나옴 | `시스템 설정 → 개인정보 보호 → 화면 기록`에서 OBS 허용 후 OBS 재시작 |
| iPhone 카메라가 안 보임 | iPhone 잠금 해제 후 근처에 둘 것. OBS 재시작 |
| 얼굴이 타원으로 나옴 | 4번의 `자르기/채우기` 를 빼먹은 것 |
| 전환 시 얼굴이 안 움직이고 컷됨 | 두 장면의 카메라가 서로 다른 소스다. '기존 항목 추가'로 다시 넣을 것 |
| 목소리가 웅웅거림 | 마이크가 멀다. 30cm 이내로. RNNoise 필터 확인 |
| 녹화 중 프레임 드랍 | 인코더를 `Apple VT H.264 하드웨어` 로 바꿀 것 |
